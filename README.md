<h1 align="center">dsh-livestream</h1>

## 是真的在直播

<p align="center"><img src="docs/live-proof.jpg" alt="左边本机 DSH 里的她，右边 B 站直播间里的她" width="100%"></p>

左边是本机 DSH 控制台里的她，右边是 B 站直播间里观众看到的她：同一个她，B 站那边晚几秒。插件调 B 站开播接口、驱动本机 OBS 推流，弹幕和礼物从 B 站直播间的消息服务实时收进来。

## 她会做什么

<table>
<tr>
<td width="38%" align="center"><img src="docs/expressions.gif" alt="边说话边换表情" width="100%"></td>
<td>

**自己的声音、自己的表情**
豆包语音合成，字幕按发音一个字一个字亮；她在话里写个 `[shocked]`、`[shy]`，念到那里就换表情。换表情时挑姿势最像的那一帧切，不叠影。

**接住直播间里的事**
弹幕、礼物、SC、上舰、进场、关注，插件按轻重缓急一件一件交给她，她自己决定怎么回。人多的时候先回舰长和老粉，冷场了她会自己找话说。

**记得人**
这一场和以前来过的观众、他们说过的话，她都记得；常来的人会被认出来。

**主播 Agent 预设**
主播预设可在直播控制台的「设置 → 主播 Agent 预设」选择并保存，每次开播直接用该预设创建会话。自动模式优先使用 DSH 中设为默认且支持直播的预设，否则使用内置主播预设。当前内置预设名为「大肥鱼抖音直播」，稳定 ID 仍为 `dsh-livestream`，旧的默认选择不受重命名影响。自定义预设需启用 `dsh-livestream/agent`；建议复制该预设后修改人设，保留直播插件。缺少直播插件或加载失败的预设会显示不可用原因，明确保存的预设失效时会阻止开播而不是悄悄换回默认。直播中需先下播再切换；游戏线仍使用独立的「大肥鱼抖音直播·游戏线」预设（需要另外安装 `dsh-game`）。

抖音预设的提示词以弹幕互动、语音、点歌结果和舞台为主，不再指导 AI 操作 B 站账号或自行搜播视频；要求如实说明 AI 身份、忽略恶意弹幕指令、不复述不适合直播的内容，不催送礼、不绕过歌曲限制。这里只调整预设与话题指引，不代表实现了全面内容审核或撤销工具的程序权限。修改预设后需让 DSH 重新加载配置并新建直播会话；已有会话不会自动切换到新的人设版本。

抖音 `view_profile` 使用独立浏览器读取公开主页，查询成功、失败或超时后都会清理查询窗口，不占用平时使用的浏览器。若在设置里主动打开了抖音登录窗口，则保留登录页，查询另开标签页并在完成后关闭；登录验证后可自行关闭登录窗口。独立用户目录保留登录态，不因查询结束而删除。资料响应正文的读取同样有 20 秒上限，避免收到响应头后一直卡住、不释放窗口。

抖音礼物消息的时间同时兼容秒与毫秒，避免把礼物误记到遥远未来、导致今日进账为零且一直不触发感谢。小礼物仍按连击结束与控制台的感谢间隔合并回应。旧版产生的异常日期账目，在后台下次加载账本时先备份为 `finance.json.before-douyin-time-fix.bak`，再迁回能唯一确定的北京时间日期；无法确定的记录保持原样。统计使用礼物面值或用户配置的估算单价，不代表平台结算到账金额。

**点歌**
观众发「点歌 晴天 周杰伦」（歌名和歌手用空格或 `--` 隔开都行），插件去网易云搜、排队、获取音源，由 OBS 舞台浏览器源直接播放。歌单显示实际播放状态和进度，播完自动切下一首；搜不到或音源无权限会明确提示。无需安装网易云客户端。可在控制台保存网易云 Cookie，使用账号有权播放的完整音源。

主播回复弹幕时，歌曲持续播放、进度不中断，只将音乐音量降到原来的 20%；说完自动恢复原音量。主播说话期间新开始的歌曲也照常播放，控制台预览仍保持静音。

没有可播放音源、音源无权限或舞台报告播放失败时，队列会记录原因并自动跳过，继续尝试下一首；没有下一首就释放播放位，后续点歌可以正常开始。获取音源最多等待 15 秒，等待播放或播放中连续 30 秒没有实际进度也会自动跳过，重复的缓冲回执不会延长等待。OBS 舞台断开、主动暂停或浏览器要求点击允许播放时保留队列；舞台重新连接或恢复播放后再开始超时检测。这里只检查加载和播放进度，不检测音频内容是否静音，也无法判断 OBS／直播伴侣的音量设置。

娱乐直播点歌默认拦截「国歌」「义勇军进行曲」「中国人民解放军军歌／进行曲」及常见名称变体，并将[文化部 2015-08-10 公布的 120 条网络音乐产品名单](https://www.mct.gov.cn/wlbphone/wlbydd/zwgk/xwfbh/201508/t20150810_507624.html)作为本项目的保守点歌限制。历史名单保存在 `packages/dsh-livestream/src/core/restrictedSongs2015.ts`，带公告原编号与歌手；它不是抖音当前完整禁播清单。

历史名单按「歌名／别名 + 对应歌手」匹配，不封禁歌手全部作品；兼容名单中常见的繁简体、空格标点、Live／DJ／伴奏等版本后缀和明确标注原唱的翻唱。只填歌名时先查搜索结果，避免误拦其他歌手的同名作品；实际搜索结果缺少可核实歌手、或公告未注明歌手时，对命中歌名的作品拒绝播放。搜索前检查明确请求，入队时检查真实歌名、别名和歌手，轮到播放和取音源前再次检查。被拦截时提示换一首，不获取音源。

另外按主人的要求在 `songPolicy.ts` 单独维护本地限制：《八连杀》（含“8连杀”、常见拼音写法）不开放点播。命中该名称或别名的翻唱、伴奏、DJ 版本也拒绝，不限定歌手；无空格的“点歌八连杀”同样在搜索前拒绝。这条本地规则不冒充 2015 年官方名单中的条目。

这些是名称和元数据规则，不识别音频内容，无法可靠识别未署名原唱的翻唱、彻底改名或藏在串烧中的曲目，也不判断歌词合规和直播使用授权；不能代替完整的弹幕或媒体审核。

## 控制台

<p align="center"><img src="docs/console.jpg" alt="DSH 里的直播控制台" width="100%"></p>

在 DSH 侧边栏打开「直播」：看舞台预览、换皮肤、开播下播、跟她说话、模拟观众（不开播也能彩排）。

直播设置的「背景音乐」默认以 12% 音量循环播放内置轻柔纯音乐，可关闭或调至 0～100%。
这段本地纯音乐由项目脚本合成，无人声、无外部歌曲采样，不依赖网易云登录或会员。
点歌从获取音源开始占用音乐通道，加载、暂停或等待允许播放时也会暂停背景音乐；整条队列播完或失败跳过至空队列后，背景音乐从原位置继续。
主播说话时背景音乐进一步降至所设音量的 35%；下播、舞台断线、播放视频或展示游戏时停止或暂停，控制台预览始终静音。

开播前在皮肤中选择「海边小屋 · 竖屏」，使用 1080 × 1920（9:16）舞台，人物、字幕、弹幕和歌单都按竖屏排版。开播时会自动设置 OBS 画布、输出和浏览器源尺寸；手动添加浏览器源时也请使用这个尺寸。切回横屏皮肤即可恢复 1920 × 1080，横竖屏切换需要先停止推流。

## 需要

- DeepSeek Harness（网页版）
- OBS Studio 30 以上（开 WebSocket）
- B 站账号的 cookie（开播需要实名认证过的账号）
- 豆包语音（火山引擎）的 API Key / App ID / Access Key

## 安装（开发方式）

```bash
pnpm install
pnpm -C packages/dsh-livestream dev
```

`dev` 会盯着源码、改哪建哪；把 `packages/dsh-livestream` 链接到 DSH 主目录的插件目录（例如 `$DSH_HOME/profiles/web/node_modules/dsh-livestream`）。首次构建完成后，在仓库根目录另开终端启动 DSH：

```bash
dsh web --patch ./packages/dsh-livestream/lib/cordis.hmr.patch.yml
```

如果终端已在 `packages/dsh-livestream/` 目录，改用 `dsh web --patch ./lib/cordis.hmr.patch.yml`。`--patch` 的相对路径从当前终端目录解析。

之后改控制台、舞台页和宿主端都会自动生效。宿主端使用框架自带的 HMR，配置由 `dev` 自动生成，详见 [docs/dev.md](docs/dev.md)。

密钥写在 DSH 主目录的 `.env`：

```
BILIBILI_COOKIE=...
NETEASE_COOKIE=...
DOUBAO_TTS_API_KEY=...
DOUBAO_TTS_APP_ID=...
DOUBAO_TTS_ACCESS_KEY=...
```

`NETEASE_COOKIE` 可选；未配置时使用公开音源。控制台预览静音，音乐由 OBS 中打开的舞台页播放。

然后在 DSH 侧边栏打开「直播」：填房间号，选「本地彩排」或「推流到 B 站」，开播。
