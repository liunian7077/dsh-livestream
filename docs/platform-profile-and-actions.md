# 双平台主页查询与角色动作

直播预设同时支持 B 站、抖音。插件会把当前平台、角色及可用动作发给主播与游戏会话；切换平台或角色后会更新，观众的聊天内容不能切换这些设置。

## 抖音公开主页

普通个人号通过独立的 Chrome 或 Edge 窗口查看抖音网页返回的公开资料。电脑需安装其中一个浏览器，在控制台「设置 → 抖音主页查询」点击「打开抖音登录窗口」，手动完成登录或验证。登录状态保存在插件数据目录的 `douyin/browser/`，不会使用日常浏览器的用户目录。也可在设置中配置抖音 Cookie；网页登录状态与弹幕采集凭据分别管理，登录此窗口不会自动更新弹幕采集的 Cookie。

`view_profile` 根据当前直播平台查询：

- B 站：保留原来的观众名字、UID 和「自己」。
- 抖音：可用本场观众名字、已出现的 UID、完整的 `https://www.douyin.com/user/…` 链接或 `sec_uid`。
- 抖音的数字 UID、抖音号不能直接组成主页地址。直播消息没有携带 `sec_uid` 时，需要提供完整主页链接。
- 「自己」查看查询窗口当前登录的抖音账号；请核对是否与开播账号一致。主页不可见、未登录、验证拦截或网页接口变化时会明确返回失败。

抖音查询只采用与目标 `sec_uid` 相符的资料；从直播观众查起时还会核对 UID。缺失的统计不会填成零。已要求忘记的观众不展示、不记录主页资料。

**抖音 `send_dm` 尚未接入。** 抖音直播时调用会明确返回未发送，也不会转用 B 站私信。B 站私信功能保留。关注、禁言等依赖观众身份的 B 站工具也不能把抖音观众 UID 当作 B 站 UID 使用。

## 原版与 Q 版角色

两个角色包保留在同一个 `assets/characters/` 目录下：`dafeiyu` 为原版，`dafeiyu-chibi` 为 Q 版。两者的片段尺寸、人物取景与转场配置不同，分别作为可选角色；合并成一个清单会混用素材规格与路径。

Q 版的 106 段动画已登记为 104 个表情、动作及 2 个待机/说话循环。原有 `[laugh]`、`[shy]` 等七个标记保持兼容；新增动作如 `[click-wave]`、`[unwrap-gift]`、`[hum-song]`、`[balance-empty]`、`[spin-360]`。完整含义见对应角色包的 `ACTIONS.md` 和 `character.json`。

每个会话首次收到直播事件或角色配置变化时，插件会发送当前角色的完整标记与中文含义。标记不参与语音朗读。常用表情和自动反应会预热，其他动作首次使用时加载，避免开场下载全部动画。动作只改变角色画面，不触发真实礼物、资金或游戏操作。

## 验证边界

本地通过类型检查、构建、离线消息与工具分流验证，并用隔离数据目录检查控制台和舞台。没有登录真实抖音账号、读取真实观众主页或发送私信；实际查询还需在登录窗口完成登录后使用。抖音网页接口变化时可能需要同步适配。
