# 轻柔纯音乐

`quiet-room.wav` 是由本项目 `tools/generate-background-music.mjs` 编排并合成的 48 秒循环纯音乐。
无人声，不使用外部歌曲、录音或采样。以柔和合成电钢琴与和弦铺底，24 kHz / 16 bit / 单声道 WAV。
素材和生成脚本沿用本项目 MIT 许可。无需联网或网易云会员即可播放。

直播设置中的「背景音乐」可关闭或调整音量（默认 12%）。点歌队列优先，包括加载、暂停和等待允许播放；
队列清空后从背景音乐暂停的位置继续。主播说话时降至所设音量的 35%；下播、断线、视频和游戏期间暂停。
控制台预览不播放声音。
